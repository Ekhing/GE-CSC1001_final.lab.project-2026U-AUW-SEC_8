# Welcome to the final project repository for GE-CSC1001 – 2026U - Section 8

This project is developed as part of the **'Introduction to Computing and Programming'** course, which is part of the semester's final coursework, in the Department of Computer Science at Asian University for Women, Bangladesh.

Throughout this course, you have learned how to apply the basic concepts of **C programming** to solve real-world problems, also with **CS50**, including:
- Constants, variables, and data types
- Operators and expressions
- Input and output operations
- Conditional statements and iteration
- Arrays and strings
- Functions
- Recursion
- File I/O operations
- Writing, compiling, executing, and debugging programs


This repository is created for the submission of your Final Lab Project. 
## 📌 How to Use This Repository
- Open the GitHub repository link provided in Google Classroom.
- Click Fork to create your own copy of the repository.
- Open your forked repository.
- Click Add file → Upload files.
- Drag and drop your entire group folder directly into the upload area.
- Example folder name: Group1_AUW
- Make sure the folder contains all required files, such as index.html, style.css, script.js, images/assets, and the Final Project Report.
- Click Commit changes.
- Click Contribute → Open pull request.
- Create the Pull Request to submit your project to the original course repository.
- Wait for the me to review and merge your submission.

#### Important: Upload the whole group folder, not the files separately.

### Each group must submit:
- Complete source code
- Required input/data files
- Output files, if applicable
- Any supporting files
- Final Project Report

Please make sure your project is placed inside your assigned group folder, all files are properly organized, and the project runs correctly before submitting your Pull Request. This final submission is a chance to bring together everything you have learned throughout the course and demonstrate your ability to design and develop a complete web project.
